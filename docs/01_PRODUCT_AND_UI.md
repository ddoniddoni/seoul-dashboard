## 1. 제품 정의

**SEOUL PULSE: 서울의 선택한 장소들을 지도와 시계열로 비교하는 도시 데이터 대시보드.**

사용자는 현재 어느 장소가 어떤 혼잡 단계인지 확인하고, 관심 장소의 최근 흐름을 비교한다. 채용 검토자는 한 화면에서 시각화, 상태 관리, 데이터 모델링과 운영 품질을 확인할 수 있어야 한다.

서울시의 공식 관제 시스템, 재난 대응 시스템, 인파 안전 판단 도구를 표방하지 않는다. 혼잡 단계만으로 현장의 안전 여부를 판단하지 않는다.

## 2. 대상과 범위

### 초기 장소

강남권, 홍대권, 명동권, 여의도권, 성수권에서 각각 1개 공식 장소를 선택하는 것을 목표로 한다. 이는 후보 생활권이며 API 요청값이 아니다.

M0에서 공식 장소 목록의 정확한 명칭과 코드를 확인한다. 예를 들어 하나의 생활권에 역 주변, 공원, 관광특구가 함께 있더라도 임의로 합치지 않는다. 정식 코드가 확인된 장소 5개를 수집 대상으로 확정한다.

지도에서 제공 카탈로그 전체와 실제 수집 중인 장소를 구분한다. 미수집 장소를 여유 상태로 칠하지 않는다. 운영 수집 확장은 설정 변경과 비용 검토를 거친다. 2026-10-15 사용자 요청의 개발용 단일 조회 범위는 공식 전체 121곳으로 확장했다. 실제 배치 실행/승인 상태는 PROGRESS.md를 따른다.

## 3. 사용자 흐름

```text
개요 접속
  → 수집 대상과 원천 기준 시각 확인
  → 지도 또는 목록에서 장소 선택
  → 상세 패널에서 추정 범위와 흐름 확인
  → 최대 3개 장소를 비교함에 추가
  → 비교 화면에서 기간 변경
  → URL 공유 또는 CSV 내보내기
```

공개 화면은 실데이터만 제공한다. 저장소가 설정되지 않았거나 조회가 실패하면 오류와 다시 조회를 제공하며 합성 데이터로 전환하지 않는다.

## 4. 페이지와 URL

| 경로 | 내용 |
| --- | --- |
| `/` | 한 화면 상황판: 전체 혼잡 분포, 지도, 장소 순위와 20곳 현황. 장소 선택 후 인구 흐름 |
| `/places` | 검색, 필터, 정렬, 페이지 이동과 비교 선택이 있는 장소 탐색 |
| `/map` | 공식 벡터 지도와 동일 정보를 제공하는 장소 목록 |
| `/data-status` | 최신성 요약과 장소별 원천/수집 시각 표 |
| `/areas/[areaCode]` | 해당 장소의 인구 흐름과 환경 정보에 집중한 상세 페이지 |
| `/compare` | 장소 간 시간대별 비교 |
| `/data-info` | 출처, 추정치 설명, 수집 정책과 데이터 상태 |
| `/demo` | 기존 링크 호환용. 실데이터 현황으로 이동 |

화면 데이터셋은 `dataset=live|demo`로 표현한다. 생략하면 서버가 설정한 기본 모드를 따른다. 내부 링크와 공유 URL은 현재 데이터셋을 유지한다.

| URL 상태 | 규칙 |
| --- | --- |
| `area` | 선택한 장소 코드. 선택 해제 시 제거 |
| `q` | 장소명 검색. 최대 50자, 300ms 입력 지연 처리 |
| `level` | 하나 이상의 혼잡 단계. 허용 enum만 사용 |
| `sort` | `congestion`, `population`, `name`, `sourceTime` |
| `places` | 비교할 코드 목록. 중복 제거, 최대 3개 |
| `range` | `24h` 또는 `7d` |
| `dataset` | 실제와 합성 데이터를 구분하는 필수 공유 정보 |
| `scenario` | 이전 링크 호환용으로 무시. 새 링크에는 포함하지 않음 |

장소가 필터 밖으로 나가도 선택 상세를 임의로 다른 장소로 바꾸지 않는다. "선택한 장소가 현재 필터에서 제외되었습니다"와 선택 해제 동작을 제공한다. 뒤로/앞으로 가기도 복원한다.

## 5. 개요 화면

### 데스크톱 구성

사용자 요청(2026-11-10)에 따라 큰 모니터에 계속 띄워두는 한 화면 상황판으로 변경했다. CSS 뷰포트 너비 1280px 이상, 높이 800px 이상에서는 화면 높이를 기준으로 상단 지표, 가운데 지도와 인구 흐름, 하단 20곳 목록을 배치한다. 지도와 차트가 남은 높이를 나눠 쓰며 정상 현황에서 페이지 스크롤 없이 전체 장소를 읽는다. 이보다 작거나 브라우저를 확대하면 세로 흐름으로 전환해 글자와 조작 영역을 유지한다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 좌측 메뉴 │ SEOUL PULSE / 종합 현황  전체화면 / 자동 확인    │
│           │ 서울 주요 장소 현황 / 수집 상태 / 한국 시각     │
├──────────────┬──────────────┬──────────────┬──────────────────┤
│ 여유 장소    │ 보통 장소    │ 약간 붐빔    │ 붐빔 장소        │
├──────────────┴──────────────┴────────┬─────┴──────────────────┤
│ 서울 장소 지도 / 혼잡 범례    │ 혼잡 단계 높은 순           │
│ 공식 장소 표식과 영역        │ 추정 인구 적은 순           │
├──────────────────────────────┴─────────────────────────────┤
│ 전체 장소 20곳 / 4열 5행 또는 5열 4행 / 추정 범위와 상태  │
└──────────────────────────────┴──────────────────────────────┘
```

지도 범례에는 전체 20곳의 마지막 저장 자료를 혼잡 단계별로 집계한다. 갱신 지연 및 만료도 포함하며 자료 없음은 확인 불가로 구분한다. 상단 지표도 마지막 관측의 네 혼잡 단계를 집계한다. 원천 시각, 자료 보유 범위와 지연/만료/누락 상태를 바로 아래에서 구분해 표시한다. 자료가 없는 장소를 여유나 0명으로 집계하지 않는다.

기본 메인은 장소 미선택 상태이며 지도 옆에 장소별 순위를 표시한다. 순위, 지도와 하단 목록은 같은 URL의 area를 변경하고 순위 패널을 선택 장소의 그래프로 전환한다. 전체 현황 버튼/로고/종합 현황 메뉴는 선택을 해제하고 순위로 돌아간다. 명시적인 area 링크는 선택 상태를 유지한다. 화면 이동 없이 20곳의 인구 흐름을 살펴볼 수 있다. 하단 ‘장소별 현황’은 장소명 16px과 인구 범위 16~20px, 혼잡 배지를 두 줄로 배치하고 네 열 사이 여백을 둔다. 공통 원천 시각과 최신성은 헤더에 한 번 표시하며 서로 다르면 장소별 최신성을 유지한다. 각 행의 툴팁과 접근성 이름에 정확한 원천 시각/상태를 포함하고 헤더에서 자료 시각 표를 연다. 검색, 필터, 정렬과 비교 선택은 장소 탐색으로, 날씨와 상세 정보는 왼쪽 선택 장소 메뉴로 연결한다. 5분 기록 표와 자료 시각 표는 기존 MUI Dialog에서 읽는다. 수집 중단, 지연, 누락과 오류 상태를 숨기지 않으며 내용이 늘어날 때는 접근성을 우선한다.

상단 전체화면 버튼은 브라우저 Fullscreen API로 화면을 채우며 왼쪽 메뉴를 잠시 숨긴다. 종료 버튼 또는 Esc로 원래 메뉴를 복원하고 사용자의 사이드바 접힘 설정은 변경하지 않는다. 모바일은 세로 배치와 서랍 메뉴를 유지한다.

2026-11-11: 종합 현황 전용 하단의 추정치 설명, 최근 수집 시각과 ‘출처와 해석’ 링크 줄을 제거했다. 현황판은 장소별 현황 목록에서 끝나며 원천 시각과 수집 상태는 기존 자료 상태에서 확인한다. 하단 전용 그리드 행도 제거해 남은 높이를 분석 영역에 배정한다.

이 도식은 레이아웃 명세이며 구현 이미지가 아니다. 상단의 큰 홍보 배너, 장식용 세계 지도, 의미 없는 원형 게이지는 만들지 않는다.

### 마지막 관측 지표 정의

| 표시 | 계산 | 주의 |
| --- | --- | --- |
| 여유 / 보통 / 약간 붐빔 / 붐빔 | 유효한 인구 값과 원천 시각이 있는 장소의 마지막 혼잡 단계별 수 | 지연/만료를 포함한 마지막 관측이며 현재 상황을 보장하지 않음 |
| 자료 보유 범위 | 유효 관측이 있는 장소 수 / 전체 모니터링 대상 수 | 실제 활성 수집 수와 구분 |
| 원천 시각 | 같은 시각이면 한 번, 서로 다르면 가장 오래된 시각부터 최근 시각까지 | 수집 시각으로 대체하지 않음 |
| 혼잡 확인 불가 | 값/유효 시각이 없거나 혼잡 단계가 unknown인 장소 수 | 여유나 보통에 포함하지 않음 |
| 자료 최신성 | 기존 30분/60분 기준에 따른 최신/지연/만료/누락 수 | 별도 상태 버튼으로 정확한 시각 표를 열 수 있음 |

지표는 화면 필터와 무관한 전체 모니터링 범위를 대상으로 한다. 분류 가능한 자료가 없으면 네 단계는 `—`로 표시한다. 일부 자료만 있으면 그 범위 내에서 집계하고 제외한 장소 수를 명시한다. 오래된 관측을 최신으로 재분류하거나 기준 시각을 바꾸지 않는다.

## 6. 지도

기본은 MapLibre GL JS와 공식 장소 영역 자료를 가공한 GeoJSON을 이용한 **장소 영역 지도**다. 외부 배경지도 호출 없이도 장소 영역, 위치 표식, 이름과 범례가 동작해야 한다. 무료 타일 서버를 무제한 배경지도처럼 전제하지 않는다. 구현 근거: S10, S11.

지도 배경은 어두운 단색이며, 검증된 공식 장소 영역들을 표시한다. 배경 도로와 지명 타일은 필수가 아니다. 배경을 추가할 경우 공급자 이용조건과 출처 표시를 별도로 확정한다.

공식 영역이 아직 확보되지 않았다면 "지도 자료 준비 중"을 표시하고 목록을 제공한다. 실제 장소 경계를 임의의 사각형으로 만들어 대체하지 않는다.

현재 M1 위치 개요는 공식 공개 자료를 표시용 SVG로 가공한 고정 지도다. 자치구 경계는 배경이며 관측값을 채색하지 않는다. 공식 장소 도형/표시 위치와 합성 관측값은 각각 구분한다. 같은 장소를 링크와 목록에서 키보드로 선택할 수 있고, 지도만 실패하면 목록/상세를 유지한다. 출처, 경계 기준일과 가공 범위는 `sources/seoul-overview.meta.json`에 기록했다. 아래의 MapLibre 카메라/확대축소와 전체 검증은 이후 M4 목표다.

| 동작 | 요구사항 |
| --- | --- |
| 선택 | 영역/표식 클릭 시 `area` 변경, 해당 목록 행 강조 |
| 호버 | 장소명, 혼잡 단계, 추정 범위, 원천 시각 요약 |
| 필터 | 지도와 목록에 같은 필터 적용 |
| 자동 갱신 | 데이터만 갱신하고 카메라와 선택 유지 |
| 확대/축소 | 버튼 제공, 과도한 자동 이동 금지 |
| 자료 없음 | 회색 처리와 "미수집" 또는 "자료 없음" 문구 |
| 오류 | 지도만 실패해도 목록과 상세는 계속 이용 가능 |

지도 색은 공식 장소별 혼잡 단계의 시각화다. 장소 사이 공간의 인구를 보간한 밀도 히트맵을 그리지 않는다. 역 주변과 관광특구처럼 영역 크기가 다르므로 인구 수만으로 인구 밀도나 위험도를 표현하지 않는다.

## 7. 장소 목록과 상세

목록은 장소명, 혼잡 단계, 추정 인구 범위, 원천 기준 시각, 자료 상태와 비교 선택으로 구성한다. 기본 실데이터 화면은 모니터링 20곳을 탐색한다. 공식 전체 카탈로그 121곳은 별도로 유지한다. 지도 옆 목록은 5곳을 넘으면 3곳씩 페이지를 나눈다. 선택한 지도 표식이 있는 페이지를 열고 페이지 상태는 URL에 보관한다. 검색/필터는 현재 페이지가 아닌 전체 목록에 적용한다. 관측이 없는 장소는 자료 없음으로 표시하며 가짜 값을 채우지 않는다. 지도는 전체 표식을 표시하되 선택한 장소의 이름만 펼쳐 겹침을 줄이고 나머지 이름은 MUI 툴팁과 목록에서 제공한다.

2026-11-11 장소 탐색 배치: `/places`는 1280×800 CSS 픽셀 이상에서 남은 화면 높이를 목록에 배정한다. 실제 목록 너비에 따라 최대 4열, 높이에 따라 들어가는 행 수를 계산해 페이지 크기를 결정한다. 검색창, 하단 페이지 이동과 자료 최신성, 비교 표시줄의 공간도 포함한다. 마지막 페이지와 적은 검색 결과의 카드는 원래 행 크기를 유지한다. 작은 창/모바일/확대 화면에서는 한 페이지에 최대 3행을 표시하고 자연스럽게 세로로 읽는다. 검색/필터/정렬 변경은 페이지를 초기화하며 비교 선택은 페이지 이동에도 유지한다. 페이지 번호는 URL에 저장하고 화면별 표시 수는 현재 공간에 맞춰 계산한다.

장소 탐색과 지도 옆 목록의 각 장소는 1px 닫힌 테두리와 8px 모서리를 가진 카드로 묶는다. 카드 간격은 가로/세로 12px이며 배경과 카드 표면을 구분한다. 두 겹의 중립색 그림자와 상단의 얕은 하이라이트로 높이를 표현하고, 호버 시 그림자 깊이만 조정한다. 라이트/다크별 그림자 농도를 구분하며 위치 이동이나 기울이기는 사용하지 않는다. 장소명/혼잡 단계/인구 범위는 상세 링크 영역에, 원천 시각/최신성과 비교 버튼은 경계선으로 분리한 하단에 표시한다. 선택 또는 비교 중인 카드는 파랑 테두리와 기존 선택 문구로 구분한다. 키보드 포커스는 조작 영역 안쪽의 2px 테두리로 표시한다. [MUI 카드의 기본/보조 동작 분리](https://mui.com/material-ui/react-card/)와 [Carbon 타일의 경계 및 상호작용 상태](https://www.carbondesignsystem.com/building-blocks/core/components/tile/guidelines)를 참고했다.

혼잡 단계 정렬은 단계의 내림차순, 같은 단계는 장소명 순으로 고정한다. 이는 "서울 전체 혼잡 순위"가 아니라 "모니터링 장소의 혼잡 단계 정렬"이다. 인구 규모 정렬은 별도 옵션이고 그 기준을 명시한다.

상세 패널에는 장소명과 코드, 혼잡 설명, 최소/최대 추정 인구, 데이터 기준 시각, 수집 시각, 최근 24시간 차트, 비교 추가, 즐겨찾기와 독립 상세 페이지 링크를 제공한다.

2026-11-11 상세 화면 배치: CSS 뷰포트 1280×800 이상에서는 제목 옆에 장소 선택/자료 상태/전체 장소를 배치하고, 인구 흐름과 환경 정보를 남은 높이에 나란히 표시한다. 차트는 높이에 맞춰 늘어나며 기록 표, 최대 구간과 누락 안내는 유지한다. 오른쪽에서 중복되던 장소명/인구 수치를 줄이고 자료 해석, 원천/수집 시각과 날씨에 집중한다. 비교 선택 표시줄도 같은 화면 높이에 포함한다. 모바일/낮은 창/확대 화면과 내용이 늘어나는 오류 상태에서는 자연스러운 세로 흐름을 유지하고, 본문 overflow를 막아 자료를 잘라내지 않는다. 원본 기록 표는 기존 대화상자 안에서 스크롤한다.

날씨 카드는 실제 검증된 값이 있을 때만 추가한다. 값이 없으면 "제공된 정보 없음"으로 표시한다. 인구 자료 시각을 날씨의 기준 시각으로 재사용하지 않는다.

## 8. 차트와 비교

그래프 재설계(2026-11-08 후속 요청)에서는 시간대별 비교가 쉬운 MUI X Charts 세로 막대그래프를 사용한다. 원본은 10분 기록으로 유지하고, 화면에서 한국 시간 정시 기준 1시간 구간마다 마지막 유효 관측을 선택한다. 막대 높이는 해당 관측의 `(최소값 + 최대값) / 2`인 추정 범위 중앙값이다. 시간 평균이나 방문자 누적 수, 확정 인원으로 해석하지 않는다. API와 서버의 집계 계약은 변경하지 않는다.

막대는 차분한 파란색, 표시된 시간별 대표값 중 가장 높은 막대는 밝은 파란색으로 구분하고 해당 시간대와 정확한 추정 범위를 텍스트로 요약한다. 0부터 시작하는 인구 축, 4시간 간격 한국 시간 눈금, 조회 시작/끝 날짜와 시각을 표시한다. 첫/끝의 일부 시간대도 유지하고 툴팁에서 부분 구간임을 알린다. 기록이 전혀 없는 시간은 null로 남기며 원본 10분 누락 구간 수도 표시한다. 툴팁은 장소, 원천 기준 시각, 추정 범위, 혼잡 단계와 해당 시간의 기록 보유 수를 제공한다. 원본 전체 10분 기록은 별도 표로 읽을 수 있다.

| 항목 | 규칙 |
| --- | --- |
| 시간축 | 실제 ISO 시각으로 배치, 사용자 표시는 한국 시간 |
| 결측 | 빈 버킷은 연결하지 않음, 임의 보간 금지 |
| 24시간 | 원본은 5분 버킷, 화면 막대는 1시간별 마지막 유효 관측값 |
| 7일 | 1시간 버킷의 마지막 유효 관측값 |
| 축 | 기본 절대 인구 축, 비교 장소에 동일 기준 |
| 툴팁 | 장소명, 원천 시각, 범위, 혼잡 단계와 집계 방식 |
| 과거 부족 | 보유 시작 시각과 "기록 수집 중" 안내 |
| 예측 | MVP에서 제외, 도입 시 미래 영역과 점선으로 분리 |

원천 자료가 같은 시각에 반복 수신되어도 관측점은 하나다. 5분 수집도 원천 지연과 수집 실패로 누락될 수 있으며 원천의 모든 변화를 보장하지 않는다.

### 장소 비교 (2026-11-08 구현)

`/compare?dataset=live|demo&places=코드1,코드2,코드3`에서 최대 3곳을 비교한다. 도시 현황 목록의 비교 버튼은 장소 상세 링크와 분리한다. 선택한 장소는 하단 비교 표시줄에 모이고 두 곳 이상 선택하면 비교 화면으로 이동할 수 있다. 선택은 URL이 소유하고 검색/필터/페이지 이동에도 유지한다. 네 번째 장소를 선택할 수 없게 하고 먼저 한 곳을 해제하도록 안내한다.

비교 화면에는 검색 가능한 MUI 다중 선택, 선택 순서에 맞는 상태 카드와 동일 축의 시간대별 막대그래프를 제공한다. 카드에는 혼잡 단계, 추정 인구 범위, 인구 기준/자료 수집 시각, 최신성을 표시한다. 장소별 관측 시각과 영역 크기가 다를 수 있으므로 인구 규모를 혼잡도나 안전 순위로 표현하지 않는다. 시연과 실데이터 모드에는 같은 모니터링 20곳을 검색 후보로 제공한다. 공유 링크가 시연 미제공 장소를 포함하면 해당 장소의 자료 없음 상태를 유지한다.

비교 이력은 기존 공개 history API로 한 번에 요청하며 모든 장소에 같은 from/to와 시간 구간을 사용한다. 그래프의 인구축 최댓값은 비교 자료 전체에서 한 번 계산해 공유하고, 1시간별 마지막 관측을 표시한다. 색상은 URL의 선택 순서에 대응하고 카드/그래프/범위 표에서 일치한다. 없는 시리즈와 결측 시간은 다른 장소의 값이나 0으로 채우지 않는다. 시간별 범위 비교 표와 툴팁에서 장소별 실제 관측 시각을 확인한다.

선택이 0~1곳이면 선택 안내를 표시하고 비교 이력 요청은 하지 않는다. 재조회 실패 시 같은 선택 조건의 마지막 정상 자료만 유지한다. live/demo는 query key로 분리하고 전환 시 이전 모드의 조회를 취소/제거한다. 공유 대화상자는 현재 조건을 담은 링크와 복사 버튼을 제공하며, 자동 복사 실패 시 직접 선택할 수 있는 읽기 전용 입력을 유지한다. 링크는 조회 조건을 공유하며 수치를 고정하는 스냅샷은 아니다.

현재는 24시간 비교만 제공한다. 7일 URL은 준비 중 안내와 24시간 기록을 표시하며 가짜 과거를 만들지 않는다. 즐겨찾기, CSV와 지도 확대축소는 이번 구현 범위에 포함하지 않는다. 자동 동작 테스트의 실행 여부는 PROGRESS.md를 따른다.

## 10. 디자인 기준

사용자 결정(2026-10-14): 디자인 라이브러리는 MUI다. 기존 화면과 이후 기능에 Material UI 컴포넌트, 공식 Material Icons와 무료 MUI X Charts를 사용한다. 색상/글꼴/간격/반응형 토큰은 `src/theme/tokens.ts`, theme와 컴포넌트 기본 스타일은 `src/theme/theme.ts`가 기준이다. 화면별 조정은 MUI `sx`로 작성한다. 기본 HTML 위젯이나 별도 UI 라이브러리로 디자인을 분산하지 않는다. 공식 SVG 지도 도형은 데이터 자산이며 지도 패널/표식/설명은 MUI를 사용한다.

네온 발광, 유리 효과, 장식용 그라디언트, 과한 그림자, 큰 둥근 카드와 튀는 이모지는 사용하지 않는다. 차트 색은 비교 장소 간 일관성을 유지하며 혼잡 단계의 의미 색과 혼동하지 않게 범례를 제공한다.

## 11. 반응형과 접근성

현재 첫 화면은 1200px 이상에서 분석 2열, 768px 이상에서 지도와 목록 2열이다. 1200px 미만의 분석 영역과 768px 미만의 탐색 영역은 단일 열이며 KPI는 768px 미만에서 2열이다. 고정 뷰포트 높이와 패널별 강제 축소를 없애 낮은 창과 확대 화면에서도 그래프 읽기 공간을 보존한다. 브라우저 시각 확인은 PROGRESS.md에 기록하며 자동 E2E 실행과 구분한다.

모바일 비교 차트는 하나의 화면에서 읽을 수 있도록 툴팁과 범례를 조정한다. 테이블이 필요한 경우 해당 영역 안에서만 가로 스크롤하고 페이지 전체가 넘치지 않게 한다.

주요 동작은 키보드로 수행 가능해야 한다. 다이얼로그 포커스 복귀, 명확한 focus ring, 차트의 텍스트 요약, 지도 대체 목록을 제공한다. 자동 갱신 때 포커스를 이동하거나 모든 숫자를 스크린리더로 반복 낭독하지 않는다. 동작 감소 설정을 존중한다.

### 개발용 정기 수집 표시 (2026-10-16)

실데이터 개요 응답의 meta.collection으로 선택한 주기의 수집 중/대기/일시 중지/중지/상태 확인 불가를 구분한다. 정기 작업이 살아 있을 때만 실제 설정된 5분, 10분 또는 30분마다 모니터링 20곳를 수집한다는 안내를 표시하고 다음 수집 예정과 최근 완료 시각을 자료 상태에서 제공한다. heartbeat가 30초 넘게 갱신되지 않으면 실행 중으로 표시하지 않는다. 원천 관측 기준과 수집 시각/다음 예정 시각을 구분한다. 화면의 자동 확인과 새로고침은 저장된 자료만 읽는다. 정기 실행 이력이 없으면 기존 수동 수집 안내를 유지한다.

2026-11-11: 실데이터 페이지 상단의 ‘저장 자료’ 배지와 상시 수집 설명 배너는 표시하지 않는다. 수집 주기/방식은 자료 상태와 데이터 안내에서 확인한다. 자료의 기준 시각, 지연/만료와 조회 실패 표시는 해당 자료 가까이에 유지하며 합성 데이터의 식별 표시는 별도로 유지한다.

## 12. 사이드바 워크스페이스 구성 (2026-11-09)

사용자 요청에 따라 기존 상단 가로 메뉴를 왼쪽 사이드바로 교체했다. 이 절이 기존 화면 배치 설명보다 우선한다. 새로운 외부 데이터나 행사/상권 기능은 추가하지 않는다.

- 데스크톱 1200px 이상에서는 232px 고정 사이드바를 표시하며 햄버거 버튼으로 76px 아이콘 레일로 접는다. 접힌 상태는 화면 전용 Context가 메뉴 이동 동안 유지하며 새로고침하면 기본 상태로 돌아간다.
- 1200px 미만에서는 햄버거 버튼으로 MUI 임시 Drawer를 연다. 닫기 버튼, 배경 클릭과 Escape로 닫고 메뉴 선택 시 서랍을 닫는다. 접힌 데스크톱 메뉴에는 툴팁과 접근성 이름을 제공한다.
- 메뉴는 종합 현황, 장소 탐색, 지도 보기, 장소 비교, 자료 상태다. 데이터 안내는 메뉴에서 숨기며 기존 `/data-info` 페이지는 유지한다. 선택한 장소가 있으면 별도 상세 바로가기를 표시한다. 활성 메뉴와 현재 위치를 사이드바와 상단에 표시한다.
- 종합 현황은 핵심 지표 4개, 장소 선택, 넓은 인구 흐름 차트와 혼잡 분포, 지도/목록 순서다. 장소 탐색은 넓은 카드 목록을 제공하며 기존 검색/필터/정렬/비교 선택을 재사용한다.
- 지도 표식과 장소 목록에서 선택하면 실제 `/areas/[areaCode]` 상세로 이동한다. 상세에는 해당 장소의 차트와 환경 정보만 표시하고 전체 장소 지표를 반복하지 않는다. 상세의 선택창으로 다른 장소를 열 수 있다.
- 자료 상태는 전체 자료 최신성 지표와 기준 시각/수집 시각 표를 제공한다. 최근 수집 결과(수신 성공, 인구 미제공, 형식 확인 필요, 요청 실패, 수집 전)와 원천 최신성을 별도 열로 구분한다. 수신에 성공해도 원천 시각이 오래되면 갱신 지연일 수 있음을 설명한다. 기존 모달에서도 같은 정보를 확인할 수 있다.
- 메뉴 링크는 데이터 모드, 검색/필터와 비교 선택을 유지한다. 화면 내부 조건 변경은 현재 경로를 유지한다. 실제/합성 표시와 결측/지연 해석은 유지한다.
- 미구현 결제, 계정, 보고서나 알림 메뉴를 만들지 않는다. 7일 이력과 즐겨찾기는 별도 범위다. 지도 확대와 이동은 아래 후속 변경을 따른다.

## 13. Unslop 기반 세부 정리 (2026-11-09)

사용자가 감사 결과에 동의해 가벼운 정리 범위를 적용했다. 기존 메뉴, 섹션 순서, 한국어 시스템 글꼴, 파란 강조색과 데이터 의미를 유지한다. 이 절의 크기/간격 기준이 이전 배치 설명보다 우선한다.

- 제품: 서울 주요 장소의 혼잡도와 관측 인구를 비교하는 분석 화면
- 성격: 차분함, 정확함, 높은 정보 밀도
- 세계: 서울 지도와 시간별 관측 기록
- 주요 시각 요소: 넓은 인구 흐름 차트와 실제 장소 지도
- 고유한 디테일: 장소명, 원천 기준 시각, 기록 상태를 일정한 형식으로 표시

지표 카드 패딩은 16px, 숫자는 32px로 줄인다. 데스크톱 메뉴 행은 36px, 행 간격은 4px, 메뉴 아이콘은 18px로 통일한다. 모바일 메뉴는 44px 이상을 유지하고 공통 헤더 기준 높이는 64px다. 본문은 14px, 보조 정보는 12px, 기본 굵기는 400/500/600을 사용한다. 인구 범위의 음수 자간을 제거하고 tabular-nums와 기존 고정폭 글꼴을 유지한다.

혼잡도 배지의 느낌표/장식 기호, 지표 카드의 색점 후광, 비교 선택창의 강조 테두리/그림자를 제거했다. 혼잡 단계 색과 장소별 비교 색상은 의미가 있으므로 유지한다. 상단에는 합성 데이터 표시를 명확히 남기고 사이드바의 중복 설명을 줄인다. 모바일 제목/설정, 장소 선택/탐색 링크를 각각 같은 줄로 묶어 차트를 위로 올린다. 긴 원천 장소명은 줄바꿈을 허용한다.

이미지나 장식 애니메이션을 추가하지 않았다. 기존 포커스 표시, 메뉴 동작과 reduced-motion 대응을 유지한다. 디자인 검토 기준: Damir Sokolovsky의 [Unslop](https://heydamir.design/unslop), CC BY 4.0.

## 14. Unslop 전면 개선 (2026-11-09)

사용자가 전면 개선을 요청했다. 이 절의 배색과 배치 기준이 13절의 가벼운 정리보다 우선한다. 제품 방향은 서울 장소별 관측을 읽는 차분하고 정확한 분석 화면이다. 주요 시각 요소는 시간별 인구 그래프와 공식 지도이며, 장소 코드와 원천 기준 시각을 반복 가능한 관측 정보 형식으로 사용한다.

- 짙은 남색 배경을 흑연 계열 중성색으로 바꾼다. 배경 #111315, 패널 #191c1f, 경계 #34393f, 보조 글자 #a9b0b8을 사용한다. 파랑은 주요 데이터와 동작에, 혼잡 단계 색은 상태 구분에 사용한다.
- 4개 지표는 개별 카드 대신 하나의 요약 영역에 묶는다. 데스크톱 4열, 모바일 2열이며 숫자 32px와 얇은 구분선을 사용한다. 최신 자료 기준과 누락 설명은 유지한다.
- 종합 현황의 주 그래프와 보조 패널은 데스크톱 2.5:1 비율을 기본으로 하되 보조 패널 최소 폭 260px을 보장한다. 장소 식별과 마지막 추정 범위를 양쪽에 배치하고 좁은 화면에서는 세로로 쌓는다.
- 인구 차트는 데스크톱 300px, 모바일 260px 높이다. 시간별 마지막 관측의 범위 중앙값을 표시하는 막대와 최고 시간대 강조, 0 기준 축, 정확한 범위 툴팁과 기록 표를 유지한다. 결측 구간을 채우지 않는다.
- 혼잡 분포는 얇은 가로 막대로 바꾸고 불필요한 세로 격자를 제거한다. 자료 보유 수, 지연 포함 여부와 최신성 비율의 설명은 유지한다.
- 지도는 중성색 도형과 실제 장소 색상을 사용한다. 768px 이상에서 자치구 이름을 표시하며 지도 최대 폭은 680px이다. 목록 높이가 커져도 지도는 상단에 정렬한다.
- 장소 목록에 공식 코드를 표시하고 인구 범위를 20px로 강조한다. 비교 카드는 굵은 색 테두리를 없애고 장소 코드와 그래프 색으로 식별한다. 비교 그래프는 각각 중성 배경에 배치하고 동일 시간축과 인구축을 유지한다.
- 공통 입력 배경, 표 행 hover, 패널 헤더와 스켈레톤을 같은 테마로 통일한다. 신규 장식 이미지나 애니메이션은 추가하지 않는다. 기존 키보드 포커스와 reduced-motion 대응을 유지한다.

### 사이드바 열기와 닫기 위치 (2026-11-09)

로고는 왼쪽 네비게이션 최상단에 고정하고 접기/펼치기 버튼은 데이터 안내 아래 맨 하단에 둔다. 메뉴 영역만 스크롤되며 하단 버튼은 항상 보이도록 유지한다. 두 상태에서 로고 아이콘과 버튼 위치를 유지하며 이름과 설명만 접을 때 숨긴다. 모바일은 닫기 버튼을 같은 네비게이션 하단에 배치하며, 메뉴가 숨겨졌을 때의 진입을 위해 상단 왼쪽 열기 버튼을 유지한다.

네비게이션 하단의 접기/펼치기 버튼은 왼쪽 패널을 표현하는 MUI ViewSidebarOutlined 아이콘과 상태별 문구를 사용한다. 펼친 상태에서는 아이콘과 사이드바 접기 문구, 접힌 상태에서는 44px 아이콘 버튼과 사이드바 펼치기 툴팁을 표시한다. 얇은 테두리로 이동 메뉴와 구분한다. 항상 보이는 데스크톱 네비게이션에서는 햄버거를 사용하지 않는다. 모바일에서 숨겨진 메뉴를 여는 상단 진입 버튼은 햄버거를 유지한다.

2026-11-11: 접기/펼치기 바로 위의 테마 전환을 단일 MUI Button으로 제공한다. 별도 스위치 없이 해/달 아이콘과 현재 모드 문구 전체가 클릭 영역이다. 라이트 모드를 누르면 다크로, 다크 모드를 누르면 라이트로 전환한다. 접힌 메뉴에서는 아이콘 버튼, 모바일 메뉴에서는 아이콘과 문구를 표시한다. 툴팁은 전환할 모드를 안내하고 접근성 이름에는 현재 모드와 전환 동작을 함께 넣는다. 지도, 차트, 혼잡 배지, 표와 대화상자가 함께 전환된다.

참고: [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/radix/sidebar)의 PanelLeftIcon 토글 패턴과 [Atlassian 사이드바 개선 안내](https://community.atlassian.com/forums/discussion/3144347/a-full-height-sidebar-for-better-navigation)의 발견 가능성/툴팁 원칙. 외부 UI 라이브러리를 도입하지 않고 기존 MUI에 맞춰 적용했다.

## 15. 시연의 이력 범위 확정 (2026-11-09)

사용자 결정으로 실제 인구 흐름은 최근 24시간만 제공한다. 기존 문서의 7일 조회/7일 내보내기 계획보다 이 결정이 우선한다. 기록이 부족하거나 수집이 끊긴 시간은 빈 구간으로 유지하며 합성 값으로 채우지 않는다. 장소별 마지막 현황은 보존하고 지연 상태와 원천 시각을 함께 표시한다. 운영 보존/삭제 기준은 데이터 문서 10절을 따른다.


### 지도 확대와 이동 (2026-11-10)

- 종합 현황과 지도 보기의 지도 헤더에 현재 배율, 축소, 확대와 서울 전체 보기 버튼을 제공한다. 100~400% 범위에서 50%p씩 변경하며 한계 배율의 버튼은 비활성화한다.
- 확대 후 마우스 또는 한 손가락으로 드래그해 이동한다. 드래그 직후 장소 링크를 열지 않으며 지도를 영역 밖으로 완전히 밀어낼 수 없게 이동 범위를 제한한다. 기본 배율에서는 모바일 페이지의 세로 스크롤을 유지한다.
- 지도에 키보드 포커스가 있으면 +/− 키로 배율, 방향키로 위치를 바꾸고 Home 또는 0 키로 전체 보기를 복원한다. Tab으로 화면 밖 장소에 접근하면 해당 위치를 보여준다. 동일한 장소 목록도 계속 제공한다.
- SVG 경계와 장소 링크는 같은 카메라 좌표로 이동한다. 표식과 선택 장소 설명은 화면상의 크기를 유지한다. 낮은 상황판에서는 말풍선의 중복 인구 행을 숨겨 장소명과 상태가 잘리지 않게 하며 인구 범위는 옆 그래프와 전체 목록에서 유지한다. 상황판에서는 패널의 전체 폭과 남은 높이를 활용하고 1280×800 이상에서 기존 한 화면 배치를 유지한다.
- 배율/위치는 해당 지도 컴포넌트에만 보관하며 자료 재조회로 초기화하지 않는다. 외부 타일, 추가 지도 API나 위치 권한은 사용하지 않는다.


### 포트폴리오 공개 경험 개선 (2026-11-10)

- 상단을 마지막 관측 기준의 네 혼잡 단계로 바꾸고 최신성은 보조 상태 행으로 분리했다. 원천 시각 범위와 자료 보유 수를 명시한다. 수집 상태와 원천 최신성은 서로 다른 상태로 유지한다.
- 1280~1439px 상황판은 4열 5행을 유지하고, 1440px 이상에서는 5열 4행으로 20곳을 표시한다. 글자 크기를 유지하며 지도와 차트에 더 많은 높이를 배분한다. 800px 미만 높이에서는 세로 흐름을 유지한다.
- 메인 그래프 하단에 기록된 시간별 마지막 관측의 범위 중앙값이 가장 큰 구간과 해당 추정 범위를 표시한다. 같은 최대값이 여럿이면 함께 안내하고, 실제 하루 전체의 최고 인구로 표현하지 않는다. 시간대가 하나뿐이면 추가 기록을 기다리는 안내를 제공한다. 키보드 포커스/툴팁으로 계산 기준, 원천 시각과 기록 수를 확인할 수 있다.
- 비교 화면의 무선택 상태에서 상권, 도심 관광지, 공원 세 조합을 제공한다. 공식 장소를 선택해 같은 조회 경로로 들어가는 바로가기이며 추천 순위나 합성 자료가 아니다. 한 곳이 이미 선택되어 있으면 그 장소를 유지한 추가 선택 버튼을 제공한다. 선택과 최근 24시간 범위는 URL에 반영한다.
- README는 문제, 구현 기능, 설계 결정, 화면과 실제 검증/운영 범위를 중심으로 재작성했다. 이전 실행 기록은 docs/archive에 보존했다.


### 전체 현황을 기본 진입으로 변경 (2026-11-10)

- 첫 `/` 진입의 강남역 자동 선택을 제거했다. 과거 `/demo` 경로도 장소를 명시하지 않으면 전체 현황으로 연결한다. 로고와 종합 현황 메뉴도 전체 화면으로 돌아가는 진입점이다.
- 혼잡 분포와 지도, 20곳 목록은 전체 모니터링 범위를 유지한다. 선택이 없을 때 오른쪽에는 혼잡 단계 높은 순과 추정 인구 적은 순을 나란히 보여준다. 각 최대 4곳, 800~899px 높이의 모니터에서는 최대 3곳을 표시한다. 전체 탐색은 기존 장소 탐색으로 연결한다.
- 혼잡 단계는 공식 네 단계 순서만 사용하고 같은 단계는 공동 순위다. 인구는 추정 범위 중앙값의 오름차순이며 범위와 원천 시각을 함께 표시한다. 동률은 공동 순위와 장소명순으로 처리하고 잘려 보이지 않는 동률 장소도 순위 계산에는 포함한다.
- 값/유효 시각이 없는 장소는 제외하고 제외 수를 표시한다. unknown 단계는 혼잡 순위에서 제외하되 유효 인구 범위가 있으면 인구 순위에는 포함할 수 있다. 마지막 관측 기준으로 지연/만료를 포함하며 현재 상황이나 방문 추천, 안전 순위로 표현하지 않는다.
- 순위/지도/목록을 선택하면 해당 장소의 최근 24시간 인구 흐름을 보여준다. 전체 현황 버튼과 장소 선택창의 전체 현황 항목으로 복귀할 수 있다. 무선택은 정상 화면이며 빈 기록 안내로 처리하지 않는다.

### 혼잡 단계와 인구 순위의 색상 구분 (2026-11-11)

- 기존 흑연 배경과 제목/수치/설명 글자색 구분을 유지한다. 색은 마지막 관측의 상태와 인구 순위에 집중한다. 여유는 초록, 보통은 노랑, 약간 붐빔은 주황, 붐빔은 빨강, 확인 불가는 회색이다. 라이트에서는 같은 의미의 진한 색을 사용한다.
- 상단 혼잡 분포는 단계별 상단 선과 유효한 수치에 색을 적용한다. 0곳과 자료 없음은 보조 글자색으로 낮추고, 실제 해당 장소가 있는 단계만 배경을 옅게 채운다.
- 혼잡 순위의 행 왼쪽 선, 순위 숫자와 옅은 배경은 실제 혼잡 단계의 색이다. 단계가 높을수록 배경 농도를 조금 높인다. 제목도 마지막 관측 중 가장 높은 단계를 따르므로 모두 여유인 화면을 빨강으로 강조하지 않는다. 공동 1위라는 이유로 붐빔 색을 적용하지 않는다.
- 추정 인구 적은 순은 제목, 행 왼쪽 선, 순위 숫자와 인구 범위에 파랑을 사용한다. 각 행의 혼잡 배지는 실제 단계를 유지한다. 인구 수나 순위에서 위험도를 추정하지 않는다.
- 20곳 목록에도 같은 단계의 왼쪽 선을 적용하고 약간 붐빔/붐빔은 옅은 배경을 추가한다. 선택한 장소는 기존 파랑 선택 상태를 유지한다. 혼잡 배지는 패널 색을 기준으로 배경을 계산해 행의 색과 겹쳐 글자 대비가 낮아지지 않게 한다.
- 기존 혼잡 단계 이름, 추정 범위, 원천 시각, 자료 최신성과 공동 순위 표시를 유지한다. 키보드 포커스는 행 안쪽의 2px 테두리로 구분하고 전환 효과는 배경색에만 적용한다.

### 배포 전 사용성 보완 (2026-11-11)

지도는 화면에서 클릭 영역이 가까운 장소를 숫자 표식으로 묶는다. 숫자는 장소 수이며 혼잡도나 인구 합계가 아니다. 선택하면 장소명/혼잡 단계/추정 범위를 가진 목록이 열리고 확대하면 개별 표식으로 나뉜다. 공식 좌표는 바꾸지 않는다. 비교 화면은 현재값 카드를 압축해 24시간 그래프를 위로 올린다. 1800px 이상 큰 현황판은 순위의 장소명과 수치를 키운다. 최초 실패, 보유 자료의 재조회 실패와 수집 상태 미확인을 구분한다. 데이터 안내 메뉴와 삭제한 안내 footer는 다시 노출하지 않는다.
